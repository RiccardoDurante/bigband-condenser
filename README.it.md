# Big Band Condenser

Versione italiana del README. Vedere README.md per la versione in inglese.

**Stato:** M1 - Project Initiation Baseline

Tool open source Python che trasforma automaticamente partiture big band in
formato MusicXML in condensed score (particella analitica) in formato MusicXML
strutturate in 4 sistemi:

- Sistema 1 - Reeds (doppio pentagramma, concert pitch)
- Sistema 2 - Brass (doppio pentagramma, concert pitch)
- Sistema 3 - Rhythm section melodica (con chord symbols)
- Sistema 4 - Drum set (slash notation e rhythmic notation)

Repository privato in fase di Initiating. Diventera pubblico al completamento
della milestone M1.
